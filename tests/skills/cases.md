# Domain Skill Cases

- UI/UX: an existing component system should be reused before creating duplicate primitives; keyboard and focus states are considered.
- Animation: a transition has a purpose, timing/easing, cancellation, and reduced-motion path.
- 3D: asset complexity and renderer budget are established before effects; loading and fallback exist.
- Scroll World/Fly-by: one normalized timeline maps progress to camera/scene state; reverse navigation works.
- Content + Code Optimization: content edits preserve meaning while code performance changes use a baseline and re-measurement.
- SEO: canonical, robots, sitemap, metadata, and structured data are checked without claiming rankings.
- Security: findings distinguish confirmed vulnerabilities from hardening recommendations.
- Reviewer: findings include severity, evidence, impact, and recommendation without an overall score.
