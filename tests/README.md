# Tests

The test suite checks repository contracts and behavioral invariants.

## Behavioral cases

Cases describe expected decisions rather than exact prose. A compliant implementation should discover facts before asking, challenge material problems, preserve user authority, and report verification limits.

## Contract coverage

- `core/cases.md` — end-to-end lifecycle.
- `skills/cases.md` — domain behavior.
- `challenge/cases.md` — evidence-backed challenge.
- `project-discovery/cases.md` — proportional discovery.
- `adapters/cases.md` — adapter portability.
