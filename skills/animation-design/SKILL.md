# Animation Design

## Purpose

Design purposeful interface motion using timing, easing, sequencing, state transitions, accessibility, and performance constraints.

## Core Principle

Motion should communicate state, hierarchy, continuity, or spatial relationship—not merely add movement.

## Scope

Micro-interactions, transitions, entrance/exit choreography, timing, easing, interruption, reduced motion, and performance.

## Discovery

Inspect existing motion libraries/tokens, CSS animations, component states, and performance patterns. Route continuous spatial camera journeys to scroll-world-flyby.

## Capability Requirements

Classify material capabilities as FULL, SUITABLE, CONSTRAINED, or UNSUITABLE from evidence available in the current session. Inspect actual model/agent/tool/environment availability; a documented capability is not evidence that it is callable now. Never claim an observation or verification that the available tools cannot support.

## Interaction

Ask about motion personality only if conventions are absent and the choice materially affects UX.

## Challenge Handling

Challenge motion that delays actions, harms focus, creates vestibular risk, or adds measurable performance cost.

## Execution Workflow

Purpose → trigger/end state → properties → duration/easing → sequencing/interruption → reduced motion → implementation → repeated-use test.

## Verification

Verify state transitions, cancellation, reduced-motion behavior, focus, cleanup, and layout stability. Runtime is needed for claims about perceived smoothness.

## Reporting

Report purpose, timing, easing, accessibility behavior, implementation, and evidence.

## Completion Criteria

Motion has a purpose, coherent states, reduced-motion behavior, and evidence-backed performance claims.
