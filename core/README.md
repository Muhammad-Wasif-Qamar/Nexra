# Core Contracts

`core/` contains supporting orchestration contracts. Canonical installable skills remain under `skills/`.

## Components

- `orchestration/PIPELINE.md` — adaptive end-to-end lifecycle.
- `registries/skill-registry.yaml` — canonical skill inventory.
- `execution/EXECUTION-CONTRACT.md` — bounded change contract.
- `verification/VERIFICATION-CONTRACT.md` — evidence model.
- `reporting/REPORTING-CONTRACT.md` — evidence-aligned reporting.
- `specification/BEHAVIOR.md` — shared behavioral invariants.

Core contracts may be referenced by documentation and tooling but must not create duplicate skill definitions.
