# Behavioral Invariants

1. Discover before asking.
2. Do not ask for reliably discoverable facts.
3. Questions must have a material decision consequence.
4. Subjective preferences are not errors by default.
5. Technical challenges require evidence.
6. User decisions are not silently overridden.
7. Capability limitations are disclosed.
8. Verification claims are evidence-bounded.
9. Execution stays within approved scope.
10. Completion is tied to observable criteria.
11. Provider-specific behavior stays in adapters.
12. Graceful degradation is preferred to false confidence.
